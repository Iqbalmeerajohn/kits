# Kits by Iqbal

Static storefront for website templates and AI marketing prompts for Indian local businesses, hosted on GitHub Pages at https://iqbalmeerajohn.github.io/kits/

- `index.html`, `css/`, `js/`, `img/`: the store. Gumroad links and prices live in `PRODUCTS` at the top of `js/store.js`.
- `preview/`: live demos of the templates (fictional businesses, generated by `tools/build.py`).
- `tools/`: build (`build.py`), headless QA (`qa.py`) and the shared template engine (`sitekit.js`).

Made by Sheik Iqbal Meera John, https://iqbalmeerajohn.github.io/portfolio/
